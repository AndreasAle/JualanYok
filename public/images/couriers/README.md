# Logo kurir

Taruh file di sini dengan nama kode kurirnya, huruf kecil, format PNG dengan
latar transparan — misalnya `jne.png`, `tiki.png`, `jnt.png`, `sicepat.png`,
`anteraja.png`, `pos.png`, `ninja.png`, `gojek.png`, `grab.png`, `paxel.png`.

Begitu file-nya ada, checkout otomatis memakainya. Selama belum ada, tiap kurir
tampil sebagai monogram berwarna khas mereknya — tidak ada yang rusak dan tidak
ada daftar yang perlu diubah.

Ukuran yang cukup: 96x96 piksel.
